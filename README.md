CampusSkill — Платформа обмена навыками и воркшопов
1. Обзор системы
CampusSkill — веб-платформа для студентов, позволяющая менторам проводить воркшопы и мастер-классы, а участникам — находить, записываться и посещать их с последующей обратной связью.
Роли пользователей
Роль	Возможности
Гость	- Просмотр каталога воркшопов, карточек, профилей менторов
Участник - Запись на воркшопы, лист ожидания, отзывы, прогресс
Ментор	- Создание воркшопов, управление участниками, обратная связь
Администратор	- Модерация, управление тегами, блокировка

2. Функциональные требования
2.1 Профили менторов
Навыки (с тегами), опыт, образование

Формат проведения: онлайн / офлайн / гибрид

Цена: бесплатно / платно (с указанием стоимости)

Рейтинг и отзывы, статистика проведённых воркшопов

Портфолио, ссылки на соцсети

2.2 Создание воркшопов
Название, описание, программа (модули/тайминг)

Дата и время, длительность

Максимальное число участников

Требования к участникам (уровень, оборудование)

Теги навыков, формат, цена

Статусы: черновик → опубликован → набор → проведён → завершён → отменён

2.3 Запись и лист ожидания
Запись при наличии мест

При заполнении — автоматическое попадание в лист ожидания (FIFO)

При отмене участника — уведомление первому в очереди с окном подтверждения (например, 24 ч)

Подтверждение записи (автоматическое или ручное — на выбор ментора)

Напоминания: за 24 ч и за 1 ч до начала (email/push)

2.4 Личный кабинет ментора
Список созданных воркшопов (по статусам)

Список участников (подтверждённые / ожидание / отменённые)

Обратная связь: отзывы, оценки, сводная статистика

Управление расписанием, отмена/перенос

2.5 Личный кабинет участника
Предстоящие воркшопы, история участия

Оставленные отзывы

Прогресс по навыкам (на основе посещённых воркшопов и тегов)

2.6 Рейтинги, теги, рекомендации
Оценка воркшопа (1–5) + текстовый отзыв; оценка ментора

Система тегов навыков (иерархия/связи)

Рекомендации похожих воркшопов (по тегам, рейтингу, истории участника)
